### 관찰

**어휘 2계열이 실제로 작동했다** (런 N). 사용자 표현 → 도구명 → 개발자 어휘(`doctest`,
`executable documentation`) → B·C 계층(`skill OR MCP server`) 순으로 확대했고, **WebFetch 7회로
원문을 열었다.** 판정의 결정적 근거가 스니펫이 아니라 README 원문에서 나왔다 —
"검증 없는 '해결' 판정 금지" 규율이 지켜졌다.

**혼동 후보를 갈라냈다** (런 N). `pytest-markdown-docs`·`mktestdocs`는 이름상 요구사항과
일치하지만 **실행만 하고 출력 비교는 하지 않는다**(예외 유무만 확인). `mdsh`는 출력을 문서에
다시 써넣는 방향이라 요구사항과 반대. 이 구분이 판정의 갈림길이었다.

**부재를 부재라고 하지 않았다** (양 런). N은 "마크다운 블록 실행+출력 대조 전용 Skill/MCP
확인 불가", O는 "한글 조판 전용 CSS 시스템은 '없다'가 아니라 이 검색에서 안 나왔다,
국내 폐쇄망·사내 시스템은 닿지 않는다". 티어 실험의 1순위 실패(부재단정)를 피했다.

**이해충돌을 자발적으로 공시했다** (런 N). 세션 스킬 목록에 사용자의 블로그 파이프라인이
있는 것을 보고 "완전 신규가 아니라 인접 아이디어이며 판정이 '만들자'로 기울 편향이 있다"고
먼저 밝히고 반대 논거를 작성했다. 그리고 **그 논거를 받아들여** 판정을 "Configure만"에서
"Configure + 얇은 스킬"로 옮겼다 — 형식적 알리바이가 아니었다.

**전제가 규칙을 이겼다** (런 O). "Figma 미사용" 전제를 받고 Figma 자원을 한 번도 제시하지
않았다. 소스 계층을 플랫폼 네이티브(CSS) → 오픈소스 토큰 → 한국어 전용 시스템으로
재편성했다. 실패 20번("입력 어휘가 규칙을 이김")의 반대 방향 사례.

**거버넌스 경고를 비용 논거로 전환했다** (런 O). 1인 전제에서 거버넌스는 실체가 없는데,
억지로 팀 얘기를 만들지 않고 "소비자가 1명이므로 거버넌스·문서·기여 규칙은 순수 낭비"로
Create 기각 근거에 편입했다.

**locale 축의 크기를 다시 쟀다** (런 O). 한글 조판을 심층 locale gap으로 예상했으나,
`text-autospace`(Baseline 2025-11)·`word-break: keep-all`·`light-dark()`가 이미 표준이라
남은 신규는 CSS 30줄 규모로 잘렸다. 실패 16번(가변성 × gap 깊이)의 **반대 방향 오판**
— 깊다고 과대평가하는 것도 오판이다. 덧붙여 `word-break: auto-phrase`는 한국어 미지원이며
BudouX 측이 "한국어는 띄어쓰기가 있어 불필요"라는 입장임을 확인해, 낭비 경로를 미리 닫았다.

### 한계
- **각 n=1**이다. 등재 값은 되지만 수치로 쓸 값은 아니다.
- **정탐 0건**이다. 두 런 모두 훅 반송이 없었으므로 이 관찰이 보여준 것은 게이트의
  판별력이 아니라 **무간섭**이다. 판별력 근거는 런 C·H·M과 회귀 스위트가 따로 댄다.
- 미확인 항목이 판정문에 남아 있다(런 O: 웹폰트 라이선스, `text-autospace` 브라우저별 표).
  판정문이 스스로 `[미확인]`으로 표기했으므로 규율 위반은 아니나, 채택 전 확인이 필요하다.

### 새로 나온 관찰 유형 셋

**1. 부재 주장 반증 — 지금까지 없던 표본 유형.** 원장의 기존 지표는 "판정자가 부재단정을
했는가"였다. 이번엔 반대로 **기획자가 쓴 부재 주장을 판정자가 검색으로 반증**했다(런 R·S).

- R: "자동차엔 긴급출동이 있는데 휠체어엔 없다" → 국립재활원 등록부에 긴급출동 태그가 붙은
  센터 80곳+, 강서구 조례에 명문화. **단 판정자는 국내 근거(3건)와 해외 사례(2건)를 분리하고
  해외 쪽은 "한국 적합성 낮음 · 로컬라이즈 기회"로 표시**했다 — 실패 15번(locale 축 누락)을
  피한 정탐 사례다.
- S: "지도 앱이 엘리베이터 고장을 반영 안 한다" → 맞지만 **관 앱 계층 미탐색**. 서울교통공사가
  2017년부터 무계단 경로 + 고장 실시간 알림 + 우회 경로를 운영 중. 실패 2번(어휘·계층
  불일치)의 교과서 사례이며, 이번엔 판정자가 그 계층을 찾아냈다.

**2. 자작 난제 적발 (런 S).** 기획서가 "핵심 AI 난제"로 꼽은 "역 구조도 PDF 비정형 추출"이
이미 개방 API(편의시설 위치정보·최단경로이동정보·빠른하차정보)로 구조화돼 있었다. 판정자는
이걸 부재 기각보다 더 치명적이라고 판정했다 — **AI 대회 제출물인데 AI 난제가 남지 않는다.**
기존 실패 목록에 없던 유형이다.

**3. 기획자 자체 판단 반박 (런 P).** 기획자가 "AI 계층은 스킬 수준에서 끝난다"고 스스로
낮춰 평가했는데, 판정자는 **"자기평가가 오히려 후하다 — 이미 남이 배포해 209★를 받은
Action 수준"**이라며 더 낮췄다(`dkamm/pr-quiz`, MIT). 자기 평가를 아래로 정정한 첫 사례다.
